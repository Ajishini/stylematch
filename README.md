# 👗 StyleMatch – Fashion E-commerce Website

🔗 **Live Demo:** [Visit StyleMatch](https://stylematch-git-main-developpp.vercel.app/)

StyleMatch is a fashion e-commerce website developed using React. It allows users to explore clothing and accessories for men and women, search and filter products, manage their cart and wishlist, and discover matching outfit suggestions.

## 📌 Project Overview

StyleMatch aims to make fashion shopping easier by helping users explore products and discover outfit combinations. Users can browse available items and view matching bottoms and accessories based on a selected top.

The project was developed to gain practical experience in frontend development, React components, interactive user interfaces, and responsive web design.

## ✨ Key Features

- 👕 Browse clothing and accessories for men and women.
- 🔍 Search for products.
- 🎯 Filter products to find suitable items.
- 🛒 Add products to the shopping cart.
- ❤️ Add products to the wishlist.
- 👗 Explore matching bottoms and accessories based on a selected top.
- 📱 Responsive and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **JavaScript** — Interactive functionality
- **React** — Component-based frontend development
- **Bootstrap** — Responsive layouts and UI components

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Ajishini/stylematch.git
```

**2. Navigate to the project folder**

```bash
cd stylematch
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm start
```

If the project uses Vite, run `npm run dev` instead. Check the `scripts` section in `package.json` to confirm the correct command.

**5. Open the application**

Open the local URL displayed in your terminal.
